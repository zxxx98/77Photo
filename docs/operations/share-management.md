# 分享链接管理

在 Web「设置 → 我的账户 → 我的分享」查看有权管理的分享链接。在照片或文件夹的分享对话框选择「管理已有分享」，可直接筛选该资源的链接。列表可按有效、已过期、已撤销和资源不可用筛选；每项显示资源名称与类型、创建时间、有效期和是否设置了密码。选择「打开原资源」可回到照片或文件夹，选择「撤销」并确认后，新的公开访问立即失效。失败时保留确认操作，可直接重试。

服务器只保存分享 token 的哈希。旧链接无法从管理列表重新复制；需要新链接时，在原资源旁选择「新建分享」。撤销无法恢复原链接。已经下载完成或已经获得授权并开始发送的数据无法远程收回。

普通成员只能管理当前属于自己的资源；管理员可管理所有分享，包括原资源已经不存在的遗留记录。照片移入回收站时，其单照片链接自动撤销；恢复照片不会重新启用这些链接。文件夹链接仍然有效，但不会显示回收站照片。永久删除照片或空文件夹后，管理员仍可看见并撤销保留的管理记录。

API 为 `GET /api/v1/me/share-links` 和 `DELETE /api/v1/me/share-links/{id}`。列表支持 `status`、`resource_type`、`resource_id`、`cursor` 和 `limit` 参数。Cookie 写请求需要 CSRF token；移动端 Bearer 请求沿用现有认证规则。管理响应不包含公开 token、密码哈希或服务器路径。

升级会执行 `011_share_management.sql`，为存量链接按当时仍存在的资源回填所有者与名称；原资源已不存在的旧记录只由管理员管理。升级前按[备份与恢复](backup-restore.md)制作照片数据根与 SQLite 的一致性备份。若需要回退，先保留升级后数据，再恢复配套的旧版照片与数据库快照；仅换回旧程序无法撤销数据库迁移或保留升级后的用户操作。
