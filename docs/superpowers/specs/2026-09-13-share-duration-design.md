# 分享链接有效期选择设计

## 目标

将分享链接有效期从当前“按钮样式的选项卡”调整为单选列表。用户仍只能选择一个有效期，但 checkbox 外层不再呈现为按钮，也不使用交互式 `button` 包裹表单控件。

## 交互与结构

- `ShareDialog` 的有效期选项使用 `radio`，因为 `1 day`、`7 days` 和 `Forever` 互斥。
- 每个选项使用独立的 `label`，使文字和 radio 都能触发选择，并保留键盘与辅助技术可访问性。
- 选中值仍由现有 `duration` state 管理，提交给 API 的 `duration` 值不变。
- `shareDurations`、`selectShareDuration` 和分享成功提示逻辑保持不变。

## 视觉方案

- 采用纵向列表，三项之间用细分隔线区分。
- 保留原有暖白、slate 和 accent 色彩体系。
- 选项包含主标签与简短辅助说明；选中状态通过 radio 原生状态和轻量背景/文字强调体现。
- 不给选项添加按钮边框、圆角卡片或按钮 hover 位移；创建链接的提交按钮保持现有按钮样式。
- 在移动端继续纵向排列，确保可点击区域和内容宽度舒适。

## 错误处理

分享链接创建、密码输入和错误提示行为不变。本次只调整有效期控件语义、结构和样式，不改 API 或状态流转。

## 验证

- 更新分享对话框规则测试，明确有效期选项使用互斥的 radio 语义。
- 运行分享模块测试、前端全量测试、TypeScript 类型检查和生产构建。
- 检查生成的 JSX 中有效期选项不存在 `button` 包裹，并确认移动端样式仍能正常排列。
